# ▶️ Getting Started

## Clone Repository

```bash
git clone https://github.com/ArpitChoubey/SeleniumProgramsUsingPython.git
```

Navigate into project

```bash
cd SeleniumProgramsUsingPython
```

Install Selenium

```bash
pip install selenium
```

Run any example

```bash
python SeleniumPrograms/Test_Lab001.py
```
